{# {{ icon('cooking') }} Get started #}
  • {{ icon('shelves') }}

    Stock manager

    Designed for minimal effort. Check ingredients in and out; configure a bank of staples like oil and spices, and My Kitchen assumes they'll always be available.

  • {{ icon('kitchen') }}

    Recipe database

    Upload your own recipes, and link each ingredient to your catalogue. The data-driven engine behind working out what's cookable.

  • {{ icon('search') }}

    See what you can make right now

    It knows what's in stock, asks what kind of recipe you're after, then surfaces all saved recipes that fit the brief.

  • {{ icon('cooking') }}

    Creative assistant

    If no existing recipes are appealing, an integrated AI model takes the brief and returns two distinctly different recipes to choose from that can be madee with what's in stock right now.

  • {{ icon('group') }}

    Multiple users

    Everyone can see each other's uploaded recipes. Configure dietary needs, allergies, preferences. Choose who you're cooking for and the generated recipes adjust accordingly.

  • {{ icon('lock') }}

    Fully local

    Self-hosted and private: stock, recipes and history never leave the host network. Only a short ingredient brief goes to the AI model for generations, and a local-model would even keep that local. More on data ›
